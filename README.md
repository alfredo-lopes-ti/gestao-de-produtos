# Sistema de Gestão de Estoque e Vendas

Aplicação em Java focada no gerenciamento de produtos e controle de estoque, desenvolvida com conceitos de Programação Orientada a Objetos (POO) e boas práticas de arquitetura.

## 🚀 Tecnologias Utilizadas
* Java 21+
* Maven (Gerenciador de Dependências)
* Git / GitHub

## 📌 Funcionalidades
* Encapsulamento e validação de atributos do produto.
* Sobrecarga de construtores para flexibilidade de cadastro.
* Sobrescrita de métodos (`toString`).

## 🛠️ Como Executar
1. Clone o repositório: `git clone <URL_DO_SEU_REPOSITORIO>`
2. Acesse a pasta do projeto e compile: `mvn compile`
3. Execute a classe principal (`App.java`).
